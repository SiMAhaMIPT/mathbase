О тренажёре

Этот тренажёр поможет отработать два ключевых раздела математического анализа: производные и неопределённые интегралы. Материал разбит на две большие части, в каждой — сначала теория, затем задачи с возрастающей сложностью.

Как устроен тренажёр

  • В каждом разделе сначала идёт теория с примерами.
  • Затем — задачи, отсортированные по сложности: ★ базовые, ★★ средние, ★★★ повышенной сложности.
  • У каждой задачи три кнопки: «Проверить ответ», «Подсказка», «Показать решение».
  • Прогресс сохраняется в браузере — можно закрыть страницу и вернуться позже.

Почему производные и интегралы вместе

Дифференцирование и интегрирование — это два взаимно обратных действия, как сложение и вычитание. Чтобы уверенно брать интегралы, нужно хорошо уметь находить производные — и наоборот, проверка интеграла всегда делается дифференцированием.

Совет. Держите под рукой таблицу производных и таблицу интегралов. В теории ниже они приведены полностью — можно распечатать или держать открытыми на соседней вкладке.

1. Производные

Теория

Что такое производная

Производная функции y = f(x) — это скорость изменения функции при изменении аргумента. Обозначается y′, f′(x) или dy/dx.

Формальное определение (предел отношения приращений):

f′(x) = limΔx→0 [f(x+Δx) − f(x)] / Δx.

Геометрически производная — это угловой коэффициент касательной к графику функции в данной точке. Физически — мгновенная скорость изменения величины.

Важно. Для успешного нахождения производных достаточно знать таблицу и правила дифференцирования. Понимание определения приходит с практикой.

Правила дифференцирования

Основные правила, которые нужно знать наизусть:

1) Константа: (C·u)′ = C·u′
2) Сумма/разность: (u ± v)′ = u′ ± v′
3) Произведение: (uv)′ = u′v + uv′
4) Частное: (u/v)′ = (u′v − uv′) / v²
5) Сложная функция: [f(g(x))]′ = f′(g) · g′(x)

Таблица производных

(C)′ = 0
(xn)′ = n·xn−1
(√x)′ = 1/(2√x)
(1/x)′ = −1/x²
(ex)′ = ex
(ax)′ = ax·ln a
(ln x)′ = 1/x
(loga x)′ = 1/(x·ln a)
(sin x)′ = cos x
(cos x)′ = −sin x
(tg x)′ = 1/cos²x
(ctg x)′ = −1/sin²x
(arcsin x)′ = 1/√(1 − x²)
(arccos x)′ = −1/√(1 − x²)
(arctg x)′ = 1/(1 + x²)
(arcctg x)′ = −1/(1 + x²)

Сложная функция

Самое важное правило для практики — правило дифференцирования сложной функции (цепное правило):

[f(g(x))]′ = f′(g(x)) · g′(x)

Простыми словами: сначала берём производную от внешней функции, оставляя внутреннюю без изменений, а затем умножаем на производную внутренней функции.

Как определить, какая функция внешняя, а какая внутренняя? Представьте, что вычисляете значение на калькуляторе. Что делаете первым? Например, в sin(2x + 1): сначала нужно вычислить 2x + 1, потом взять синус. Значит, (2x + 1) — внутренняя, синус — внешняя.

Пример: y = sin(2x + 1)

Внешняя функция — синус, внутренняя — (2x + 1).

y′ = cos(2x + 1) · (2x + 1)′ = cos(2x + 1) · 2 = 2·cos(2x + 1).

Пример: y = (x² + 3)⁵

Внешняя — степень, внутренняя — (x² + 3).

y′ = 5(x² + 3)⁴ · (x² + 3)′ = 5(x² + 3)⁴ · 2x = 10x(x² + 3)⁴.

Примеры решения

Пример 1. y = x³ + 5x² − 7x + 2

Используем правило суммы и таблицу:

y′ = (x³)′ + 5(x²)′ − 7(x)′ + (2)′ = 3x² + 5·2x − 7·1 + 0 = 3x² + 10x − 7.

Пример 2. y = x²·sin x

Правило произведения: (uv)′ = u′v + uv′.

u = x², u′ = 2x; v = sin x, v′ = cos x.

y′ = 2x·sin x + x²·cos x.

Пример 3. y = (x + 1)/(x − 1)

Правило частного: (u/v)′ = (u′v − uv′)/v².

u = x + 1, u′ = 1; v = x − 1, v′ = 1.

y′ = [1·(x − 1) − (x + 1)·1]/(x − 1)² = (x − 1 − x − 1)/(x − 1)² = −2/(x − 1)².

Типичные ошибки

  • Забыть правило сложной функции. Например, пишут (sin 2x)′ = cos 2x, а правильно — 2·cos 2x.
  • Путать порядок в правиле частного. Числитель: u′v − uv′, а не uv′ − u′v.
  • Не выносить константу. (5x³)′ = 5·3x² = 15x², а не 3x².
  • Забыть производную внутренней функции. В (2x + 1)⁴ множитель 2 теряется чаще всего.

2. Неопределённые интегралы

Теория

Что такое неопределённый интеграл

Неопределённый интеграл — это операция, обратная дифференцированию. Если F′(x) = f(x), то F называется первообразной для f, и

∫ f(x) dx = F(x) + C,

где C — произвольная постоянная. Она появляется потому, что производная от константы равна нулю: у функции много первообразных, отличающихся на константу.

Основное свойство интеграла — проверка дифференцированием:

(∫ f(x) dx)′ = f(x).

Правила интегрирования

1) Константа: ∫ k·u dx = k·∫ u dx
2) Сумма/разность: ∫ (u ± v) dx = ∫ u dx ± ∫ v dx
3) По частям: ∫ u dv = uv − ∫ v du
4) Замена: ∫ f(g(x))·g′(x) dx = ∫ f(t) dt

Таблица интегралов

∫ 0 dx = C
∫ xn dx = xn+1/(n+1) + C   (n ≠ −1)
∫ (1/x) dx = ln|x| + C
∫ ex dx = ex + C
∫ ax dx = ax/ln a + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ dx/cos²x = tg x + C
∫ dx/sin²x = −ctg x + C
∫ dx/(1 + x²) = arctg x + C
∫ dx/√(1 − x²) = arcsin x + C

Метод замены переменной

Если интеграл содержит сложное выражение, часто помогает замена переменной. Идея: ввести новую переменную t = g(x), тогда dt = g′(x) dx, и интеграл упрощается.

Пример: ∫ 2x·cos(x²) dx

Замечаем, что (x²)′ = 2x. Вводим t = x², тогда dt = 2x dx.

∫ cos(x²)·2x dx = ∫ cos t dt = sin t + C = sin(x²) + C.

Метод интегрирования по частям

Применяется для интегралов от произведений, например ∫ x·sin x dx, ∫ x·ex dx, ∫ ln x dx. Формула:

∫ u dv = uv − ∫ v du

Алгоритм: выбираем u (то, что при дифференцировании упрощается) и dv (то, что легко интегрируется), затем находим du и v.

Пример: ∫ x·e^x dx

Полагаем u = x, dv = ex dx. Тогда du = dx, v = ex.

∫ x·ex dx = x·ex − ∫ ex dx = x·ex − ex + C.

Типичные ошибки

  • Забыть + C. Неопределённый интеграл без константы — неполный ответ.
  • Путать знаки. ∫ sin x dx = −cos x + C, а не cos x.
  • Неверно выбрать замену. Замена должна упростить интеграл, а не усложнить.
  • Забыть модуль. ∫ dx/x = ln|x| + C, а не ln x.
  • Ошибка в формуле по частям: ∫ u dv = uv − ∫ v du, знак минус.
